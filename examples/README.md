# Reproducible geometry-first examples

The first executable example is a 1 m cube generated by:

```bash
python -m go_cfd.cli demo-cube ./local_cases/cube_01 --speed-ms 20
```

No CFD results are prefilled. Houses, warehouses, freestanding walls,
billboards and the cooling-tower benchmark are planned, but need verified
CAD geometry, flow conditions and reference pressure data.
